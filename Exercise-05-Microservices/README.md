## Exercise 05 — Microservices (Spring Boot "Hello World!")

### Targets

- Implement a simple "Hello World!" microservice with the Spring Boot framework, as introduced in the lecture.
- Create the project with the Maven builder and the Spring Web dependency.
- Start and stop the embedded server, and check that it runs properly.
- Know how to change the default configuration (port, application name) in `application.properties`.

### Solution

The project is in the [demo](demo/) folder. It is the "Spring Quickstart Guide" application from the lecture:

- `DemoApplication` is annotated with `@SpringBootApplication`, which turns on auto-configuration and component scanning, and provides the `main` method that starts the application with an embedded Tomcat server.
- The same class is also annotated with `@RestController`, so its methods answer HTTP requests. The `hello` method is mapped to `GET /hello` with `@GetMapping`. It reads an optional `name` request parameter (`@RequestParam`, default value "World") and returns the text `Hello <name>!`.
- `pom.xml` is the Maven build file generated by Spring Initializr: Spring Boot 4.1.2, Java 21, and the Spring Web starter (named `spring-boot-starter-webmvc` in Spring Boot 4).
- `application.properties` sets the application name (`spring.application.name=demo`). The server uses the default port 8080.

Calling the service gives:

| Request | Response |
|---|---|
| `http://localhost:8080/hello` | `Hello World!` |
| `http://localhost:8080/hello?name=Tartempion` | `Hello Tartempion!` |

## Tutorial: building the Spring Boot app in VS Code

The statement explains the steps with Eclipse and Spring Tools 4. These are the same steps in VS Code. They assume the following extensions are installed:

- **Extension Pack for Java** (Microsoft), which includes **Maven for Java**.
- **Spring Boot Extension Pack** (VMware), which includes **Spring Initializr Java Support**, **Spring Boot Tools** and **Spring Boot Dashboard**.

You also need a JDK 17 or newer (this project uses Java 21). You do not need to install Maven: the project comes with the Maven wrapper (`mvnw`), which downloads the right Maven version on first use.

### 1. Create the Spring Boot project

This replaces the Eclipse wizard "File > New > Other > Spring Starter Project".

1. Open the Command Palette with `Ctrl+Shift+P`.
2. Run **Spring Initializr: Create a Maven Project...**
3. Answer the questions one after the other:
   - **Spring Boot version**: the latest stable one (not SNAPSHOT or RC). This project uses 4.1.2.
   - **Project language**: Java.
   - **Group Id**: `com.example`.
   - **Artifact Id**: `demo`.
   - **Packaging type**: Jar.
   - **Java version**: 21 (or the version of your JDK).
   - **Dependencies**: search for **Spring Web**, select it, then press Enter to confirm.
4. Choose the folder where the project is created (here, `Exercise-05-Microservices`). VS Code creates a `demo` folder inside it.
5. When VS Code asks, click **Open** (or **Add to Workspace**) to open the new project.

The Java extension then detects `pom.xml` and imports the project. Maven downloads all the libraries (Spring, Tomcat, Jackson...), which can take a minute the first time. You can follow the progress in the status bar. The libraries appear under **Maven Dependencies** in the **Java Projects** view of the Explorer.

> If VS Code shows the warning "DemoApplication.java is not on the classpath of project ...", the Maven project was not imported. Open the `demo` folder itself with **File > Open Folder...**, or run **Java: Clean Java Language Server Workspace** from the Command Palette and reload the window.

### 2. Write the Hello World controller

Open `src/main/java/com/example/demo/DemoApplication.java` and replace its content with:

```java
package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@SpringBootApplication
@RestController
public class DemoApplication {

	public static void main(String[] args) {
		SpringApplication.run(DemoApplication.class, args);
	}

	@GetMapping("/hello")
	public String hello(@RequestParam(value = "name", defaultValue = "World") String name) {
		return String.format("Hello %s!", name);
	}

}
```

If an import is missing, put the cursor on the red word and press `Ctrl+.` to let VS Code add it.

### 3. Start the server

This replaces "Run As > Spring Boot App" in Eclipse. Any of these works:

- **Spring Boot Dashboard**: click the Spring Boot icon in the Activity Bar (left side). Under **Apps**, hover over `demo` and click the **Run** (play) button.
- **CodeLens**: in `DemoApplication.java`, click **Run** just above the `main` method.
- **Terminal**: from the `demo` folder, run `./mvnw spring-boot:run` (or `mvnw.cmd spring-boot:run` on Windows).

The output appears in the **Debug Console** (or in the terminal). The server is running when you see lines like:

```
Tomcat started on port 8080 (http) with context path '/'
Started DemoApplication in 1.079 seconds
```

### 4. Test the service

Open a web browser and go to:

- `http://localhost:8080/hello`, which shows `Hello World!`
- `http://localhost:8080/hello?name=Tartempion`, which shows `Hello Tartempion!`

You can also click the link next to the running app in the Spring Boot Dashboard, or use `curl http://localhost:8080/hello` in a terminal.

### 5. Stop the server

- In the Spring Boot Dashboard, click the **Stop** (square) button next to `demo`.
- Or click the red square in the debug toolbar at the top of the editor.
- If it was started from a terminal, press `Ctrl+C` in that terminal.

### 6. Change the default configuration

Open `src/main/resources/application.properties`. Spring Boot Tools gives auto-completion for the property names: start typing and press `Ctrl+Space` to see the suggestions, the same as in Eclipse. For example, to change the port and the application name:

```properties
spring.application.name=demo
server.port=8081
```

Restart the application. The service is now at `http://localhost:8081/hello`.

### 7. Run the tests (optional)

The project created by Spring Initializr includes a test, `DemoApplicationTests`, that checks the application starts correctly. Run it from the **Testing** view (flask icon in the Activity Bar), with the **Run Test** CodeLens in the test file, or with `./mvnw test` in a terminal.
